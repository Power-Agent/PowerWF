# B2G-Agent

B2G-Agent is a research toolkit and local browser interface for building-grid
interactions. Its Translator, Actor, and Reviewer agents interpret requests,
plan tool execution, and check contracts and physical evidence. The study uses
an IEEE 33-bus feeder, ten building energy managers, and 15-minute intervals.

See the [main README](../README.md) for requirements, data downloads, experiment
reproduction, critical file descriptions, and the local interface guide.
Run the documented installation and experiment commands from this directory.

The optional [Personal-workspace template](../Personal-workspace/README.md)
explains how private interface sessions are kept separate from formal experiments.
